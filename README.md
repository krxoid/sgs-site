# Silver Grove School — Vite + React

Static school showcase for Silver Grove School, Maheshpur/Lahartara, Varanasi. Made it to learn ReactJS.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
